# Gee Graphics POS outcomes

- [x] Deliver a dark responsive POS shell with a left navigation rail, desktop split-panel workspace, and mobile-friendly navigation and cart behavior.
- [x] Seed and display a Gee Graphics catalog containing only shirts and bandanas, with all shirt SKUs visible on the Home screen.
- [x] Price every remaining catalog item at ₱650 and display peso formatting throughout the POS.
- [x] Provide category filter chips beside the product search for All, Shirts, and Bandanas.
- [x] Provide an interactive order/cart panel where staff can add products, adjust quantities, remove line items, clear the tab, and review subtotal, tax, and total calculations.
- [x] Provide checkout with Cash or Online payment only; Online opens a modal with GCash, MariBank, GoTyme, BPI, custom locally saved methods, account name, reference number, and receipt camera upload.
- [x] Persist products, active cart, completed orders, payment methods, and settings in browser localStorage only; do not use a server, database, authentication, or external API.
- [x] Remove the Customers navigation surface and keep checkout focused on selling.
- [x] Provide order history, sales reports, inventory signals, and settings screens with locally persisted changes.
- [x] Make the app installable as a PWA with manifest metadata, standalone display, iPhone home-screen metadata, raster icons, and an offline shell service worker.
